# HANDOFF: Split Bot

Обновлено: 2026-11-04. Этот файл каждая новая сессия читает первым делом.

## Что это

Общий Telegram-бот Некита, Антона и Полины: голосом или текстом заносим общие траты в донгах, делим на троих или на пару, в воскресенье итог с минимумом переводов. Плюс очереди «байк» и «вода» вне денег.

- Спека (одобрена): `docs/specs/2026-11-04-split-bot-design.md`
- План (одобрен, режим Native): `docs/plans/2026-11-04-split-bot.md`. Интерфейсы, тесты и значения там.
- Голос через Groq API, не локальный Whisper (решение 04.11 после разбора сторожа, правило в `~/Claude Code/CLAUDE.md`).

## Как выполнять

- Скилл `superpowers:executing-plans`, задачи строго по порядку, TDD как в плане, `- [x]` в плане по мере шагов.
- Git: `git init` в Task 1, коммит после каждой задачи.
- Код плана не проходит тесты → `superpowers:systematic-debugging`, чинить минимально, отличие записать ниже в «Отклонения».
- В конце пачки: `uv run pytest -q` зелёный → обновить этот файл → сказать Некиту промпт для следующего чата.
- После Task 7 один свежий ревьюер на Opus по всему коду (так выбран Native).
