# HANDOFF: Split Bot

Обновлено: 2026-11-04. Этот файл каждая новая сессия читает первым делом.

## Что это

Общий Telegram-бот Некита, Антона и Полины: голосом или текстом заносим общие траты в донгах, делим на троих или на пару, в воскресенье итог с минимумом переводов. Плюс очереди «байк» и «вода» вне денег.

- Спека (одобрена): `docs/specs/2026-11-04-split-bot-design.md`
- План (одобрен, режим Native): `docs/plans/2026-11-04-split-bot.md`. Интерфейсы, тесты и значения там.
- Голос через Groq API, не локальный Whisper (решение 04.11 после разбора сторожа, правило в `~/Claude Code/CLAUDE.md`).

## Как выполнять

- Скилл `superpowers:executing-plans`, задачи строго по порядку, TDD как в плане, `- [x]` в плане по мере шагов.
- Git: `git init` в Task 1, коммит после каждой задачи.
- Код плана не проходит тесты → `superpowers:systematic-debugging`, чинить минимально, отличие записать ниже в «Отклонения».
- В конце пачки: `uv run pytest -q` зелёный → обновить этот файл → сказать Некиту промпт для следующего чата.
- После Task 7 один свежий ревьюер на Opus по всему коду (так выбран Native).

## Отклонения от плана

- Task 2: `offsets_for_next` ставит `name` → M, остальных двоих → M+1 (а не M, M+1, M+2 как в плане). По формуле плана тест плана не проходил (после хода Полины снова была бы Полина). Цена: если стартовать с Антона, порядок дальше Антон → Некит → Полина, а не по кругу Антон → Полина → Некит (по счётчикам и тай-брейку NAMES иначе нельзя).
- Task 4: в `parser.parse` параметр `s` keyword-only (в плане после аргумента с дефолтом, это синтаксическая ошибка). Тестов 25 вместо 23 (+ псевдоним «Никита», + неизвестная очередь). Корень «к» в `should_parse` только отдельным словом (`\bк\b`), иначе ловит «шашлык».
- Task 1: коммит-трейлер `Co-Authored-By: Claude Sonnet 5.5` (модель сессии), а не Opus 5.5 из плана.

## Заметки для пачки 2

- `Service.balance()` по плану создаёт `pay_items` на каждый вызов: при повторных `/balance` копятся дубли неоплаченных переводов. В Task 6 переиспользовать неоплаченные строки с теми же frm/to/amount (или чистить неоплаченные перед созданием) и добавить тест.
- `claude.run_claude` вызывается с `--tools ""` (как idea-bot без тулов), вживую в этой пачке не гонял, первая проверка в Task 8.
- `db.save_draft` не проверяет `question` (это делает `Service.confirm`).
