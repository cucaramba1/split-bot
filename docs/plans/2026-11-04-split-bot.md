# Split Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Telegram-бот в общем чате на троих: голосом или текстом заносим общие траты в донгах, бот делит их на троих или на пару, раз в неделю присылает итог с минимумом переводов и ведёт очереди «байк» и «вода».

**Architecture:** Один asyncio-процесс под launchd. Голос → Groq Whisper API → `claude -p` (Haiku) разбирает текст в строгий JSON → карточка-черновик с кнопками → SQLite. Деньги и очереди считает чистый код (`money.py`, `queues.py`), модель только разбирает речь.

**Tech Stack:** Python 3.12, uv, aiogram 3, python-dotenv, httpx, SQLite (stdlib), pytest. Основа и паттерны из `~/Claude Code/idea-bot`.

**Spec:** `docs/specs/2026-11-04-split-bot-design.md`

## Global Constraints

- Папка проекта `~/Claude Code/split-bot`, пакет `splitbot`, запуск `python -m splitbot`. Git, коммит после каждой задачи, сообщение `feat|fix|chore(split-bot): <что>` + строка `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Участники ровно трое, порядок фиксирован: `Некит`, `Антон`, `Полина` (`NAMES` в `config.py`). Этот порядок = порядок при равенстве в очередях и в выводе.
- Валюта только VND, целые числа. В тексте сумма выводится с пробелом-разделителем тысяч: `120 000`.
- Очереди ровно две: ключи `bike` («Заправка байка»), `water` («Бутыль воды»).
- Деление: доля каждого = `amount // len(split)`; остаток остаётся на плательщике.
- `claude -p` только с `--strict-mcp-config --mcp-config '{"mcpServers":{}}'`, модель `haiku`, таймаут 90 с.
- Голос: Groq API `https://api.groq.com/openai/v1/audio/transcriptions`, модель `whisper-large-v3-turbo`, `language=ru`, таймаут 60 с. Локальный Whisper не запускать (правило CLAUDE.md от 04.11.2026).
- Тексты бота по-русски, коротко, без длинного тире (—) нигде: ни в сообщениях, ни в README.
- Бот реагирует только в чате `CHAT_ID` и только на трёх зарегистрированных участников. Всё прочее молча игнорирует (кроме `/join` до регистрации, см. Task 6).
- Итог: воскресенье 20:00 `Asia/Ho_Chi_Minh`, не больше одного раза за ISO-неделю, после сна мака отправляется при пробуждении.
- Тесты только на `tmp_path` и фейках. Живой Telegram, живой Groq и живой claude только в Task 8.

## Review Focus

1. Двойной тап «Записать» (или тап после рестарта бота) → трата записана ровно один раз, второй тап отвечает «уже записано». Тест в Task 6.
2. Посторонний человек в чате пишет или жмёт чужую кнопку → ничего не меняется; участник жмёт кнопку чужой карточки → «это не твоя трата». Тест в Task 6.
3. Мак спал в воскресенье в 20:00 → итог уходит при пробуждении, один раз; во вторник после пропущенной недели не дублирует две недели подряд. Тест в Task 7.
4. Модель вернула имя не из списка, сумму 0 или больше 50 000 000, «на двоих» без второго человека → не записываем, карточка с вопросом. Тесты в Task 4.
5. Обычная болтовня в чате («го в кафе вечером») → бот молчит и не дёргает claude. Тест в Task 4 (`should_parse`).

### Task 4: Разбор речи в траты

**Files:**

**Interfaces:**
- Consumes: `config.NAMES`, `config.QUEUES`, `config.Settings`
- Produces:
  - `parser.should_parse(text: str) -> bool`: True, если в тексте есть цифра или одно из слов-корней `тыс|тыщ|к\b|лям|миллион|сот|двест|трист|пятьс|донг|заправ|бензин|байк|вод|купил|потратил|заплатил`. Голос всегда идёт в разбор после расшифровки через эту же функцию.
  - `parser.SCHEMA` (JSON schema): `{"kind": "expenses"|"none", "items": [{"title": str, "amount": int, "split": [str]}], "turns": [{"queue": "bike"|"water", "who": str}], "question": str|null}`
  - `parser.SYSTEM`: системный промпт. Обязательно содержит: участники `Некит (Никита), Антон, Полина`; автор сообщения подставляется в промпт, «я/мне/меня» = автор; «на троих», «на всех» или без уточнения → все трое; «на двоих с X» / «мне и X» → автор + X; «X и Y» → X + Y; суммы в донгах целым числом: «120к» = 120000, «1.2 ляма» = 1200000, «сто двадцать тысяч» = 120000; «заправил байк» / «купил воду» → turns, а не items, если сумма не названа явно как общая трата; не придумывать сумму: если её нет, `question`; болтовня без трат → `kind: "none"`.
  - `parser.Parsed` (dataclass): `items: list[dict]`, `turns: list[dict]`, `question: str | None`, `none: bool`
  - `async parser.parse(text: str, author: str, run=claude.run_claude, s: Settings) -> Parsed`
  - `parser.validate(raw: dict, author: str) -> Parsed`: чистая функция, вызывается внутри `parse`. Нормализует имена (`Никита`/`никита` → `Некит`, регистр), убирает дубли в `split`, пустой `who` → `author`. Ставит `question`, если: имя не из `NAMES`; `amount <= 0` или `> 50_000_000`; `len(split) < 2` (вопрос «на кого делим?»); очередь не из `QUEUES`. Если `kind == "none"` и нет items/turns → `none=True`.
