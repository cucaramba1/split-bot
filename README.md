# Split Bot

Общий Telegram-бот Некита, Антона и Полины: голосом или текстом заносим общие траты в донгах, бот делит их на троих или на пару, в воскресенье в 20:00 (Нячанг) присылает итог с минимумом переводов. Плюс очереди «байк» и «вода» вне денег.

## Как поставить

1. `cp .env.example .env`, заполнить `BOT_TOKEN` (@BotFather) и `GROQ_API_KEY` (console.groq.com).
2. В @BotFather: `/setprivacy` → Disable (иначе бот не видит обычные сообщения в группе).
3. Группа втроём, добавить бота.
4. `scripts/setup.sh install`. Автозапуск при логине выключен специально, бота поднимает `tools/boot-stagger`.
5. `/join` в группе: бот пришлёт id чата. Вписать его в `.env` как `CHAT_ID`, `scripts/setup.sh restart`, все трое жмут свои имена.
6. Стартовые очереди: `/queue_set`.

## Команды

- `/balance`: кто кому сколько должен, кнопки «оплачено»
- `/queue`: чей ход (байк, вода)
- `/undo`: удалить свою последнюю запись
- `/queue_set`: задать, чей ход
- `/join`, `/help`

Трата: «кофе 120к и молоко 45к на троих, чипсы 30к мне с Полиной». Бот присылает карточку, автор жмёт «Записать». Очередь: «заправил байк», «купил воду».

## Устройство

Голос → Groq Whisper API → `claude -p` (Haiku) разбирает в JSON → карточка → SQLite (`data/split.db`). Деньги и очереди считает код (`money.py`, `queues.py`). Тесты: `uv run pytest -q`. Логи: `logs/splitbot.log`.
